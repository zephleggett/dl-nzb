features

  • ❯ No daemon

    Nothing runs in the background. Open it, it downloads, it's done.

  • ⇉ Fast

    Parallel connections and SIMD yEnc decoding keep the line full.

  • ✓ PAR2 repair

    With par2-rs, my pure-Rust PAR2 library. Recovery data downloads only when it's needed.

  • ↻ Resumes

    Quit mid-download. Next time it carries on where it stopped.

  • % Availability check

    Asks the server what it has first, and warns before a download that can't be repaired.

  • ⊞ RAR extraction

    Password-protected archives too. Passwords in the NZB are used automatically.

  • ⌥ Deobfuscation

    Scrambled file names get their real names back from the PAR2 data.

  • ≤ Speed limit

    Cap the download speed so the rest of the network stays usable.

command line

Run it, it downloads, it exits.

commands

$ dl-nzb Sintel.nzb     # download
$ dl-nzb test           # test the server
$ dl-nzb config         # show the config

options

Command line options
-o <DIR>output folder
-llist the contents only
-fdownload even if it can't be repaired
--limit-rate 10Mcap the speed
--password <PW>archive password; repeat to try several
--jsonresults as JSON on stdout
-q · -vquieter · louder

config.toml

[usenet]
server      = "news.example.com"
port        = 563
username    = "you"
password    = "••••••••"
ssl         = true
connections = 20

[download]
dir         = "downloads"
speed_limit = "10M"  # optional

The first run creates this file; dl-nzb config shows where. DL_NZB_* environment variables override it. Progress goes to stderr, --json to stdout.

install

The command line tool.

shell 
$ cargo install --git https://github.com/zephleggett/dl-nzb dl-nzb

Needs Rust 1.85 or later. Or download a binary from Releases. PAR2 and RAR are built in; there's nothing else to install.
