dl-nzb

Download, repair and extract NZB files, quickly.

Native apps for Mac, iPhone and iPad, and a command line tool. One Rust core under all three, with our own optimized PAR2.

Download for Mac iPhone and iPad

what you need

  • A Usenet account: the server, username and password from your provider.
  • An NZB file.
  • A Mac, an iPhone or iPad, or any computer for the command line:
Mac
macOS 26 or later. Apple silicon or Intel.
iPhone and iPad
iOS 26 or iPadOS 26 or later.
Command line
macOS, Linux or Windows.

Download the DMG and drag dl-nzb to Applications. It keeps itself up to date.

iPhone and iPad setup guide

what it does

Fast
Many connections at once and SIMD decoding, with little memory.
Repairs
Fixes damaged downloads with par2-rs, our own optimized PAR2 in Rust. It only fetches recovery data when a download needs it.
Extracts
Unpacks RAR archives, password-protected ones too.
Checks first
Checks what the server has before downloading, and tells you when a release can't be repaired.
Resumes
Quit any time. It picks up where it left off.
Real file names
Puts back the real names when a release scrambles them.
Speed limit
Caps the download speed so the rest of your network stays usable.
One engine
The Mac and iPhone apps and the command line run the same Rust core.

command line

Install it with Cargo (Rust 1.85 or later), or download a binary from Releases.

$ cargo install --git https://github.com/zephleggett/dl-nzb dl-nzb

The first run creates a config file. Add your Usenet account to it, then:

$ dl-nzb Sintel.nzb   # download
$ dl-nzb test         # test the server
$ dl-nzb config       # show the config
