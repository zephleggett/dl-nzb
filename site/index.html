dl-nzb

Download from your Usenet server with an NZB.

A native app for Mac, iPhone and iPad, and a command line tool. No daemon, no web UI.

Download for Mac iPhone and iPad

what you need

  • A Usenet account: the server, username and password from your provider.
  • An NZB file.
  • One of these:
Mac
macOS 26 or later. Apple silicon or Intel.
iPhone and iPad
iOS 26 or iPadOS 26 or later.
Command line
macOS, Linux or Windows.

get the app

Mac

Download the DMG, drag dl-nzb to Applications, and open it. It offers each new version when one is out.

what it does

Repairs
Fixes damaged downloads with PAR2, using par2-rs, a pure-Rust PAR2 library. Recovery data downloads only when it's needed.
Extracts
Unpacks RAR archives, including password-protected ones.
Checks first
Asks the server which articles it has, and warns before a download that can't be repaired.
Resumes
Quit mid-download. Next time it picks up where it stopped.
Real file names
Gives scrambled file names their real names back, from the PAR2 data.
Speed limit
Caps the download speed so the rest of your network stays usable.

command line

Install it with Cargo (Rust 1.85 or later), or download a binary from Releases.

$ cargo install --git https://github.com/zephleggett/dl-nzb dl-nzb

The first run creates a config file. Add your Usenet account to it, then:

$ dl-nzb Sintel.nzb   # download
$ dl-nzb test         # test the server
$ dl-nzb config       # show the config
