dl-nzb
iPhone and iPad command line github

Download, repair and extract NZB files.

Native apps for Mac, iPhone and iPad, and a command line tool. All three run on one Rust core.

Download for Mac iPhone and iPad

v0.8.0 for macOS 26 or later. Release notes Mac setup guide

  1. download

    Checks what the server has before it starts. Decodes with SIMD over many connections, in little memory.

  2. repair

    Fixes damaged files with par2-rs, our own PAR2 in Rust. Fetches recovery data only when it's needed.

  3. extract

    Unpacks RAR sets, password-protected ones too, and puts back file names a release scrambled.

iPhone and iPad

Downloads keep going in the background. Finished files show up in the Files app.

Setup guide

iOS 26 or iPadOS 26 or later.

Command line

For macOS, Linux and Windows. Install with Cargo, or get a binary from Releases. The first run writes a config file for your server.

Command line guide 

$ cargo install --git https://github.com/zephleggett/dl-nzb dl-nzb$ dl-nzb Sintel.nzb
